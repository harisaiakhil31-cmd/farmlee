# Farmlee Manager — PRD

## Original Problem Statement
Pull GitHub repo "hydro-check-log" (Expo React Native + FastAPI + MongoDB app called Farmlee Manager) from `https://github.com/harisaiakhil31-cmd/farmlee`. Deploy it as a WEB app so users can open it in Chrome. User wants a permanent `.emergent.host` URL. Admin: `akhilharisai@gmail.com / Admin@123` (already seeded in code).

## What's Implemented (2026-05-22)
- **GitHub repo cloned** from `https://github.com/harisaiakhil31-cmd/farmlee` into `/app`
- **Backend (FastAPI + MongoDB)** running on supervisor:
  - Admin auto-seeded on startup from `ADMIN_EMAIL` / `ADMIN_PASSWORD` env vars
  - JWT auth + 2FA (email OTP)
  - Endpoints: tanks, environment, field tasks, weekly/monthly checks, crops, reminders, seedlings (types, batches, watering), audit log, dashboard, weekly report, calendar, Excel exports
  - Email delivery: Gmail SMTP → Resend → SendGrid → dev log fallback (dev OTP returned in response when no mail provider is configured)
  - APScheduler reminder worker (1-min interval)
- **Frontend (Expo SDK 54 + react-native-web)** built as static web bundle:
  - 34 static routes exported to `/app/frontend/dist/`
  - Served via `serve -s dist -l tcp://0.0.0.0:3000` (configured in `package.json` `start` script)
  - expo-router based navigation (login, dashboard, tanks, environment, seedlings, calendar, profile, etc.)
- **Verified working in Chrome** at the preview URL — login page renders, backend `/api/health` OK, admin login returns OTP.

## Architecture
- `/app/backend/server.py` — FastAPI app (1001 lines, single file)
- `/app/backend/.env` — MONGO_URL, DB_NAME, JWT_SECRET, ADMIN_EMAIL, ADMIN_PASSWORD
- `/app/frontend/app/` — expo-router pages (TypeScript)
- `/app/frontend/src/api.ts` — axios client using `EXPO_PUBLIC_BACKEND_URL`
- `/app/frontend/dist/` — static web bundle (generated by `yarn build:web`)
- `/app/frontend/.env` — `EXPO_PUBLIC_BACKEND_URL`, `REACT_APP_BACKEND_URL`
- Supervisor: `backend` (uvicorn on 8001), `frontend` (serve on 3000), `mongodb`

## Build / Rebuild
```bash
cd /app/frontend && yarn build:web   # rebuilds dist/
sudo supervisorctl restart frontend  # re-serve
```
