**Important note about Crops library propagation (Q2c):**
When you edit a crop's stage values in the Crops library, **future** tank readings for tanks assigned to that crop will use the new ranges automatically (because the assignment looks up the crop+stage at read-time). **Existing** tank readings keep the ranges they had at the time of recording (so historical data stays accurate).

## Architecture
- `/app/backend/server.py` — FastAPI app (single file, ~1450 lines)
- `/app/backend/.env` — MONGO_URL, DB_NAME, JWT_SECRET, ADMIN_EMAIL, ADMIN_PASSWORD, GMAIL_*
- `/app/frontend/app/` — expo-router pages (TypeScript)
- `/app/frontend/src/api.ts` — axios client using `EXPO_PUBLIC_BACKEND_URL`
- `/app/frontend/src/confirm.ts` — cross-platform `confirmAction()` + `notify()` (web Alert.alert callbacks don't fire)
- `/app/frontend/src/WebDateTime.tsx` — cross-platform date/time pickers (HTML input on web, native picker on iOS/Android)
- `/app/frontend/src/HistoryList.tsx` — reusable history+edit+delete modal
- `/app/frontend/src/DynamicCheck.tsx` — reusable dynamic-task check form (weekly + monthly)
- `/app/frontend/dist/` — static web bundle (generated by `yarn build:web`)
- Supervisor: `backend` (uvicorn on 8001), `frontend` (serve on 3000), `mongodb`
